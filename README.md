## О проекте

**HORIZONT** — это сайт-каталог велосипедных маршрутов. Пользователь может:

- просматривать список маршрутов с фотографиями и описанием;
- добавлять новые маршруты через форму;
- подписываться на журнал с живыми впечатлениями о путешествиях.

Проект разработан в учебных целях для демонстрации навыков работы с **React**, **Vite**, **React Router** и адаптивной вёрсткой.

---

## Технологии

- **React 18+** — библиотека для построения пользовательских интерфейсов.
- **Vite** — инструмент для быстрой сборки проекта.
- **React Router DOM** — маршрутизация без перезагрузки страницы (SPA).
- **CSS (Flexbox, Grid, медиазапросы)** — стилизация и адаптивная вёрстка.
- **JavaScript (ES6+)** — логика приложения (состояние, события, fetch-запросы).

Адаптивность
Проект полностью адаптивен и корректно отображается на всех устройствах:

Десктоп (≥ 769px) — полноэкранный баннер, 3 колонки с карточками.

Планшет (481–768px) — блоки перестраиваются, карточки в 2 колонки (при необходимости).

Мобильные устройства (≤ 480px) — карточки в 1 колонку, бургер-меню, блоки «О нас» друг под другом.

Ключевые адаптивные решения:

Плавное изменение размеров шрифтов через clamp() и vw;

Использование flexbox и grid для построения сеток;

Отдельный медиа-запрос для мобильных устройств с переопределением позиционирования и размеров;

Бургер-меню на основе useState для управления классом .open.
